**Problem:** Railway staging service crashes with `Cannot find module '/app/index.js'`
**Root cause:** `railway up` from `server/` directory uploads the files but Railway's Nixpacks builder doesn't recognize the Dockerfile. It's trying to use the default Node.js start command (`node index.js`) instead of the Dockerfile's `start.sh`.
**Fix needed:** Either:
- (a) Set the service's root directory to `server` via Railway dashboard (Settings → Root Directory → `server`), then link the GitHub repo and let Railway build from the Dockerfile, OR
- (b) Switch the service to use the GitHub repo (`International-AI-Design/hthd-loyalty-app`) with root directory `server` in the dashboard

**Railway dashboard URL:** https://railway.com/project/06d67ff4-be3d-4bed-aa44-ed1732d9c226
**Environment:** staging
**Service:** hthd-staging-api

## Comms Channel Quick Reference

./scripts/comms.sh send "Your message here"

# Send with priority/type
./scripts/comms.sh send -t task -p high -s "Subject" "Body"

# Check queue status
./scripts/comms.sh status
